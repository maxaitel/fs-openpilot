# Executable-command design synthesis

The goal is zero-contact vision driving on cone tracks and full R,R,L,L skidpads. Native-plan fitting has not achieved it, and unchanged perfect native futures still contact cones from standing. The next experiment changes the supervised output contract to raw native actuator requests.

Architect grounding is complete. Two independent candidates considered direct commands, residual corrections and cone planning. Candidate A proposes a 1.27-million-parameter head on nine raw visual features and route history. Candidate B proposes a smaller direct command interface with explicit observation and persistence-shortcut checks. The root proposes reusing the existing policy's 256-wide temporal and route representation instead of learning a new summarizer from 7,006 anchors. Candidate B independently supports this narrower first experiment.

The selected design takes B's distinct executed-command contract and qualification structure. It substitutes a frozen 256-wide activation at the input of `base.policy.p_node_linear_20`. A parameter-free LayerNorm of that activation and measured vx, vy and yaw rate feed a 259-to-128-to-2 SiLU head. The head has exactly 33,538 parameters. All 31,154,802 original parameters remain loaded and unchanged. Total loaded parameters are 31,188,340. Raw teacher controls supervise only the new command output. No plan loss, OP residual, PI state, ground-truth position, lateral error, cones, actuator-state copy input or future state enters the head.

The base graph already combines the exact temporal visual history, full route pulse queue and traffic convention. A forward pre-hook captures the final affine layer's input without changing outputs. The hook must fire exactly once with shape B by 256. Measured vehicle normalization is fixed at vx/10, vy/2 and yaw rate/1. Output units are 0.1 rad and 2 m/s². Input shape, field order and scales have one owner in the experimental head implementation and are stored in the package contract.

Candidate A contributes its exact temporal alignment and startup checks. Candidate B contributes its direct target provenance, all-validation-strata gate, full-history visual dependence checks, honest old-plan diagnostics, and standing-start driving qualification. The raw-feature head is deferred because it must relearn temporal and route processing with roughly 38 times as many new parameters. A residual on OP plus PI is deferred because its supervised residual requires an exact unobserved controller history through the 5 Hz collection. Cone planning is deferred because it adds perception, association, route topology and tracking qualification together.

Both candidates satisfy the command/target semantic criterion and declared observation criterion. B has the clearer checkpoint and command audit boundary. The latent graft has fewer parameters and reuses the route-responsive temporal representation. Both require the same genuine physical gates and preserved evidence. The latent bottleneck may omit clearance information; the fixed small-set overfit and full driving checks must decide that rather than assuming it is sufficient.

The installed pool has only GPT-family models. A different-family cross-judge is unavailable. The parent read both candidates and made this rubric-based selection. Independent scrutiny within the available family remains part of verification.

Before the main run, freeze the recipe and source. Prove exact ABAB unmodified base outputs, hook semantics, unchanged base tensors and flags, same-tick teacher labels, native membership, recovery receipts and 5 Hz temporal indexing. Preserve the deployed all-frozen base flags and execution context. Do not enable feature caching, BF16 or channels-last.

A TRAIN-only 32-anchor wiring test gets at most 200 updates and must reach 0.002 rad and 0.05 m/s² MAE. Its head is discarded. Passing earns one fixed 500-update run with AdamW at 1e-3, zero weight decay, batch128 with16 recovery draws, seed0, FP32 and gradient norm limit1. The loss is equal SmoothL1 on raw command error scaled by 0.02 rad and 0.5 m/s². There is no continuation or coefficient retry attached to that run.

Save steps0,100,200,300,400,500. Score all2,067 validation anchors and every validation episode. Require steering MAE0.01 rad and acceleration MAE0.25 m/s², p95 errors0.03 rad and0.75 m/s². Require the same ceilings for each episode and predeclared observation-based strata where present. Select the scheduled qualifying checkpoint minimizing the maximum normalized MAE, with earlier step on a tie. If none qualifies, retain the rejection and permit only the predeclared final step500 for exposed-case diagnosis. Do not open final cases.

Before physical qualification, require full-history visual dependence on TRAIN dynamic anchors and a saved-input native120-frame pilot covering all four20Hz phases. Record raw, bounded and mission-applied commands separately. Original plans and cone heads remain actual frozen-model diagnostics and must not be represented as the source of the executed direct command. The native referee, camera, physics, timeout and mission support stay unchanged.

This is a reversible isolated experiment. Its result, including a failure, determines the next hypothesis. The previously frozen64-run final acceptance suite remains untouched.
