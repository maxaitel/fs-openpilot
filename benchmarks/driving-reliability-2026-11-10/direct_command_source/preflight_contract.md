# Direct actuator trial preflight

Run from the `/scratch/fsop/head_trial_work` using the Spark environment with the pinned model graphs and native dataset installed. Use a new durable output directory for each complete attempt. The recipe and code must remain unchanged from audit through visual qualification. All stages fail closed and retain a failure receipt. Failed or interrupted runs are not resumed or overwritten.

1. `PYTHONPATH=src:. python .work/lab/direct_command_trial/actuator_trial.py audit --out runs/direct_command_trial1 --device cuda`
2. `PYTHONPATH=src:. python .work/lab/direct_command_trial/actuator_trial.py overfit --out runs/direct_command_trial1 --device cuda`
3. `PYTHONPATH=src:. python .work/lab/direct_command_trial/actuator_trial.py train --out runs/direct_command_trial1 --device cuda`
4. If training selects an eligible checkpoint, run `PYTHONPATH=src:. python .work/lab/direct_command_trial/actuator_trial.py visual --out runs/direct_command_trial1 --device cuda`.

The audit verifies the pinned manifest and original checkpoint, every native array and episode membership, independent recovery receipts, the 7,006 and 2,067 anchor counts, the pinned eight-slot graph context, base inventory and flags, and exact plain/hooked ABAB outputs on replay anchors. It records the immutable source inventory, source archive, the per-tensor base hashes, the fixed overfit and dynamic visual anchors, and the recovery sampling protocol. Graph files are identified by hash, not duplicated into the source archive.

The wiring gate trains a disposable head on the fixed 32 TRAIN anchors for at most 200 updates. It requires raw physical MAE at most 0.002 rad and 0.05 m/s². It never supplies weights to the main run. A failed head and receipt remain available for diagnosis.

The main run starts with a freshly seeded head. It uses one fixed 500-update recipe, FP32 and a fresh batch-local history, without a feature cache. All validation anchors are scored at steps 0, 100, 200, 300, 400 and 500. Aggregate, each episode and each nonempty frozen observation stratum must meet both MAE and p95 thresholds. The low-speed stratum uses measured vx below 2 m/s, the pulse stratum uses a nonzero value anywhere in the last nine pooled desire slots, and recovery means a validation episode with an explicitly marked recovery collection policy. No label, future trajectory or ground-truth geometry defines a stratum. Step 0 is diagnostic only. Among passing steps 100 through 500, minimum maximum aggregate MAE normalized by the two MAE limits wins, with earlier step breaking ties. If none passes, step 500 is diagnostic only. A failure does not authorize another learning-rate attempt or fresh final cases.

The visual gate uses 32 fixed TRAIN anchors with at least eight prior 5 Hz frames and measured vx at least 2 m/s. It replaces the current image pair and every valid historical image pair in both cameras with black RGB converted through the deployed RGB-to-model transform. Route and measurements stay unchanged. Normalized SmoothL1 command loss must increase by at least 10% and by more than five times the unchanged-input repeat difference. A passing visual gate does not replace the separate saved-input native 120-frame pilot or physical qualification.

Expected outputs include `audit.json`, `source.zip`, `overfit.json`, six full `step_NNN.pt` packages, six `validation_NNN.json` files, `steps.jsonl`, `train.json` and, when eligible, `visual.json`. A package contains the complete original base payload, separate command head, complete command contract, frozen recipe and provenance. Full packages can occupy roughly 1 GiB together. The script checks a 25 GiB free-space reserve and a 1 GiB output budget. It records per-step wall time, sampled GPU utilization, power and memory where `nvidia-smi` is available, and peak CUDA allocated memory. Missing telemetry is recorded as null.

The audit and training stages require the real Spark artifacts and graphs. A local shape check cannot establish replay parity, overfit, validation, the visual gate, native simulation, or zero-contact driving. No final acceptance cases are opened by these commands.
