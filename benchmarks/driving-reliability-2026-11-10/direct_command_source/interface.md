# Direct-command experiment boundary

The selected architecture and immutable requirements are in ../reliability_architecture/synthesis/README.md. This document is the shared implementation boundary. The trainer owns actuator_trial.py, recipe.json and preflight_contract.md. The evaluator owns evaluate.py, verify_command_episode.py and the native pipeline adaptation notes. Each file has one writer. No GPU work until the parent launches it.

actuator_trial.py exports NativeActuatorPolicy.load(package: Path, device: str | None = None). It returns a callable policy with reset(), model, head, command_contract, controller_name, and __call__(obs, env). model is the exact frozen original SupercomboFS, enabling the existing ImageHeadCapture and base.policy_raw capture. head is the separate executed-command module. controller_name is direct_native_actuator_v1. command_contract is one JSON-compatible complete contract. model_digest(model) covers the base only. The new package SHA binds the complete base payload, command head, recipe and source. Record a separate head state digest and both parameter counts.

The public head call is head(latent: Tensor[B,256], proprio: Tensor[B,3]) -> Tensor[B,2] of physical raw requests. The head owns parameter-free latent LayerNorm, proprio normalization, SiLU and physical output scaling. Its four affine weight and bias tensors contain exactly33,538 parameters. Every caller passes unnormalized measured vx,vy,r in that order. The verifier can independently feed the saved latent and proprio through this same serialized head and reconstruct the raw, bounded and mission-applied request. The head does not apply vehicle limits or mission intervention itself.

The package is a distinct schema with kind direct_native_actuator_v1, base_payload containing the complete original c121 checkpoint mapping, head_state, command_contract, recipe and provenance. An old checkpoint cannot be loaded as a command package. Validate base_payload with the original checkpoint validator and strict model tensor inventory. Do not forge an old controller contract around new command outputs.

The policy reuses the actual unmodified ModelPolicy for image/history processing and original plan/cone diagnostics. A one-shot pre-hook on base.policy.p_node_linear_20 captures its input B by256 and must fire once. The command head uses that latent and measured current vx,vy,r only. The old policy's proposed actions and stateful PI outputs are discarded and retained only as base_controller_diagnostic. They never actuate the car. The command head output is raw [steer rad, accel m/s²], decoded with fixed units, bounded to vehicle limits, then passed through unchanged mission braking/launch and final limits. Mission computation for discarded diagnostics has no stateful mission effect. Exactly one new direct request reaches each native tick.

The returned info preserves actual frozen plan, uncertainty and cone outputs. Move the original info['controller'] to info['base_controller_diagnostic']. Set info['controller'] to a record with kind, latent [256], proprio [vx,vy,r], raw [2], bounded [2], applied [2], and mission_override bool. This is a distinct execution contract. Metadata and auditors must never recompute executed direct actions from the old plan.

The evaluator adapts isaac_lab_fsop/evaluate.py in the experimental directory, retaining native physics, camera, 120-second timeout, physical contacts, evidence record and referee semantics. It loads NativeActuatorPolicy, writes schema4 with complete command contract and head digest, and includes both experimental module sources in the source archive. Policy calls still expose the original plan and cone heads for unchanged compositor views. Save every inference and terminal failure. The existing raw scene export and all cameras stay unchanged.

verify_command_episode.py independently reloads the exact new package, replays every saved frame through the real policy with complete temporal history, compares raw policy outputs, actual head/controller values, actions, prediction and image head at existing1e-5 tolerances, and binds all source, graph, evidence and package hashes before/after. At least the entire120-frame pilot must pass before full rendered driving. Do not use legacy plan-based controller verification for direct commands. Producer rendering remains NumPy1.26 with the existing compositor and full decode pipeline, adapted with an explicit direct-command audit rather than suppressing old action mismatches.

No base model, production source or inherited archive is edited by this experiment. No feature cache, BF16, channels-last, privileged geometric features, teacher identifiers or actuator-state inputs enter the head. Frozen feature extraction and deployed base flags/context match; copy inference features outside inference_mode before head backward where needed. GPU experiments are serialized by the parent.
